Welcome & Overview
You already make conditional decisions every day.

Before you leave the house, you check the weather. If it is raining, you carry an umbrella. If it is not raining, you may not. Before you withdraw money from a POS machine, the terminal checks whether your PIN is correct and whether your balance is enough. If both are fine, the cash comes out. If one fails, the transaction is rejected. Before a delivery rider accepts your order, the app checks whether the rider is available and whether the route is reachable.

In programming, this is called control flow. Control flow is the order in which a program evaluates its instructions. So far, most code you have seen runs straight down from top to bottom. But real programs must make decisions. They must choose between different paths based on data.

This lesson focuses on the simplest and most important form of control flow: branching with if, elif, and else. A branch allows the program to say, “If this condition is true, do this. Otherwise, do something else.”

By the end of this lesson, you should be able to:

Explain what a boolean context is and how Python decides what is truthy or falsey.
Use bool() to observe how Python interprets different values.
Write if, elif, and else blocks with correct syntax and indentation.
Use compound conditions with and, or, and not.
Trace how Python resolves multiple elif branches from top to bottom.
Identify shadowed or unreachable branches.
Use guard clauses to avoid deeply nested conditional code.
Do not rush. Conditional logic is where programs begin to feel alive. It is the difference between a script that always does one thing and a script that responds intelligently to the situation.
